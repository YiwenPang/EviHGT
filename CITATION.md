# Citing EviHGT

Identify the software as **EviHGT: Evidence-aware Heterogeneous Graph Transformer for Drug–Disease Association Ranking** and include the repository URL and commit SHA. For a new experiment, record the model variant, configuration, corpus identifier, training seed, software versions, hardware and precision. Formal paper citation metadata and a DOI are pending.

Cite the versions of [OptimusKG](https://optimuskg.ai/) and [DrugBank](https://go.drugbank.com/releases/latest) that supplied the graph and structured drug records. For runs with D1 features, also cite [ChemBERTa](https://huggingface.co/seyonec/ChemBERTa-zinc-base-v1) and [BioBERT](https://huggingface.co/dmis-lab/biobert-v1.1). Encoder revisions and input fields are listed in the [data guide](docs/data.md).
